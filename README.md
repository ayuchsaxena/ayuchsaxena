# Welcome to my world

**I like building things, one block at a time.**

Minecraft taught me to start with what I have, experiment with what is possible, and turn small pieces into something bigger. That is also how I approach AI, research, and startups: gather the right materials, try ideas, learn from what breaks, and keep crafting until something useful takes shape.

```text
       +-----------------------+
       |       IDEAS           |
       |          ↓            |
       |   EXPERIMENT  → BUILD |
       |          ↓            |
       |      SOMETHING        |
       |       USEFUL          |
       +-----------------------+
```

## What I'm crafting

- **AI and software:** turning rough ideas into tools people can use.
- **Research:** exploring questions, testing approaches, and sharing what I learn.
- **Startups:** building, talking to users, and figuring out what is worth making.

## My GitHub world

Every repository is a different build. Some are experiments; some become useful tools; all of them teach me something.

I care more about making things work than making them sound impressive. There is always another idea to test, another skill to craft, and another block to place.
